# PocketGull Brand & Theme Asset Registry

This directory contains the multi-platform design tokens, theme packages, and configuration manifests for the **PocketGull Circadian Theme Engine**.

* **Master Design System & Launch Dossier**: [`docs/BRAND_THEME_ASSETS.md`](../../docs/BRAND_THEME_ASSETS.md)

## Directory Structure

* [`android-theme/`](./android-theme/) — Material Design 3 XML (`colors.xml`, `themes.xml`), Jetpack Compose (`PocketGullTheme.kt`), and Flutter (`pocketgull_theme.dart`).
* [`chrome-themes/`](./chrome-themes/) — Manifest V3 themes for Google Chrome / Edge (`.zip` packages and source manifests).
* [`firefox-themes/`](./firefox-themes/) — Mozilla WebExtension themes (`.xpi` add-ons and source manifests).
* [`terminal/`](./terminal/) — Oh My Posh HUD configurations (`pocketgull-washi.omp.json`, `pocketgull-ophthalmic.omp.json`) and Windows Terminal schemes.
* [`windows-themes/`](./windows-themes/) — Native Windows 11/10 desktop theme files (`PocketGull-Washi.theme`, `PocketGull-Obsidian.theme`).
